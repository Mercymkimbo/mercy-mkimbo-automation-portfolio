# AI-Powered Customer Support Triage & Routing System

## Project Overview

An automated customer support triage and routing solution built using Make.com.

The system receives incoming customer support requests through a webhook, processes unstructured customer messages using AI classification logic, and applies conditional routing to direct enquiries according to their priority.

## Business Problem

Customer support teams can struggle with:
- High volumes of incoming customer requests.
- Manual ticket classification.
- Delayed identification of urgent issues.
- Inefficient ticket routing.
- Repetitive administrative work.

## Solution

I developed an automated workflow that combines webhook-based data collection, AI-powered message classification and conditional routing.

The workflow is designed to identify important information in incoming support requests and direct tickets through the appropriate operational path.

## Technologies Used

- Make.com – Workflow orchestration.
- Webhooks – Incoming request handling.
- AI classification engine – Customer message interpretation.
- Filters – Conditional routing.
- Google Sheets – Ticket tracking.
- Slack – Team notifications, where configured.

## Workflow Architecture

1. An incoming support request triggers the webhook.
2. The request data is passed to the AI classification component.
3. The AI analyses the customer message and identifies relevant priority information.
4. Conditional filters evaluate the classification result.
5. High-priority requests are directed to the designated urgent-handling route.
6. Other requests follow the appropriate standard workflow.

## Key Capabilities

- Webhook-based request intake.
- AI-assisted customer message classification.
- Keyword and urgency identification.
- Conditional routing using filters.
- Support ticket organisation.
- Urgent request escalation.

## Business Value

The solution demonstrates how workflow automation and AI classification can help customer support teams organise incoming requests, reduce repetitive manual triage and improve visibility of urgent enquiries.
